# Exercises & Projects - Web Programming (UNSJ)

Welcome to my repository! This space contains practical software systems, web applications, and object-oriented programming (OOP) projects built during my Technical Degree in Web Programming at the **Universidad Nacional de San Juan (UNSJ)**, along with specialized technical solutions designed for the modernization and digitization of the **Judiciary Power of San Juan**.

## 🛠️ Technologies & Tools
* **Languages & Cloud:** Python 3.x, HTML5, CSS3, JavaScript (ES6), Google Cloud Platform (GCP)
* **Core Frameworks & Tools:** Pandas, Streamlit, Chart.js, Flask, SQLAlchemy, Git & GitHub
* **Core Concepts:** Object-Oriented Programming (OOP), Data Pipelines, Serverless Infrastructure, Cloud DevOps, and Regex Algorithmic Engines.

## 📂 Featured Projects

### ⚖️ Judicial Informatics Applications
* 🔒 **Algorithmic Sentence Anonymizer (Python & Cloud Deploy):** An automated web system designed under the **Personal Data Protection Law (Ley 25.326)** to sanitize judicial rulings from the San Juan Judiciary. Implements strict regular expression (Regex) engines and context-based grammatical filters to mask sensitive data (citizens' names, IDs, passports, emails) in sub-second execution times without cloud performance leaks.
  * 🔗 [Live Web App Demo](https://ejercicios-proyectos-gffwpi6pggbqdbmj7z76fu.streamlit.app/)
* 📊 **Judicial Management & Analytics Dashboard (JS & Pandas):** An interactive data platform for monitoring process efficiency and case backlog across different courts in San Juan. Features a data architecture built on Python (Pandas) to model 1,000 relational records, and a vanilla JavaScript frontend managing real-time KPI re-calculations, cascading filters, search bar integrations, and hot-state data manipulation.
  * 🔗 [Live Dashboard Demo](https://santijulio.github.io/Ejercicios-Proyectos/Generador%20de%20Datos/index.html)
* ☁️ **Serverless Data Ingestion Pipeline (GCP & DevOps):** An infrastructure solution designed for automated corporate data ingest. Features a Google Cloud Storage bucket with event triggers that invoke a cloud function in Python, running data-cleaning scripts through memory pipelines before initiating streaming ingestion into the BigQuery analytical Data Warehouse.
  * 📁 [View Architecture Folder](https://github.com/SantiJulio/Ejercicios-Proyectos/blob/master/Ingesta-Cloud-GCP/README.md)
